# Photos

Every image slot on the page falls back to a striped placeholder with a caption
naming the shot. Drop a file in here with the matching name and it takes over —
no markup change needed. Missing files remove themselves, so the page never
shows a broken-image icon.

All photography prints pure black and white; the `grayscale` class from the
design system handles that, so upload colour originals.
