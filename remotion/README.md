# Remotion project

Làm video bằng React. Hướng dẫn đầy đủ (tiếng Việt): [`../docs/remotion.md`](../docs/remotion.md)

```bash
npm install
npm run dev                                   # mở Remotion Studio
npx remotion render PromoVideo out/promo.mp4  # xuất file
```

Composition có sẵn: `HelloWorld` (1920×1080), `PromoVideo` (1080×1920).
