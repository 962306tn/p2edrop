Typography

One family, two weights that matter. Size, line-height and tracking ship as a matched set at every step — tracking tightens as type grows, which is the single most recognisable trait of the system. Body copy is 17px.

Space, shape, motion

Spacing is a 4px-based scale. Sections breathe on a fluid rhythm that collapses on phones without a media query. Every transition uses the same easing curve — that consistency is what reads as unhurried.

Accordion

Does it need JavaScript?
No. The accordion is native <details>, the nav is sticky CSS, and dark mode follows the system. The only optional script is the scroll-reveal helper.
How do I rebrand it?
Override the tokens in :root after the stylesheet. No component rule hard-codes a colour, radius or duration.
Will it clash with a Shopify theme?
Every class and token is ap--prefixed, and the reset is limited to box-sizing plus element defaults inside the page.

Getting started

Install

Link the bundle, then write markup with ap- classes.

<link rel="stylesheet" href="design-system/dist/cupertino.css">

Rebrand by overriding tokens after the stylesheet — nothing else needs to change.

:root { --ap-accent: #7c3aed; --ap-link: #6d28d9; --ap-radius-lg: 8px; }

Edit the layers in src/, then rebuild the bundle.

./design-system/build.sh
